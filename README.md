## 〔 01 〕&nbsp; Features

<br>

```
🔐  SECURE AUTH          →   JWT-based login & user account management

🛒  SHOPPING CART        →   Add ingredients to cart in one click

💾  DATA PERSISTENCE     →   All your data saved securely across sessions
```

## 〔 03 〕&nbsp; Quick Start

<br>

**Clone & Install**

```bash
git clone https://github.com/your-username/recipe-sharing-platform.git
cd recipe-sharing-platform
```

**Setup Backend**

```bash
cd server
npm install
cp .env.example .env        # add MONGO_URI and JWT_SECRET
npm run start
```

**Setup Frontend**

```bash
cd client
npm install
npm start
```

> App runs on `http://localhost:3000` &nbsp;|&nbsp; API on `http://localhost:5000`
